Theme Integration

The TagConsent script is automatically injected via Shopify Script Tags. For manual integration or additional customisation, add this to your theme.liquid inside <head>:

<script>
  window.tagconsentConfig = {
    apiKey: 'YOUR_API_KEY',
    endpoint: 'https://tagconsent.com',
    platform: 'shopify'
  };
</script>
<script src="https://tagconsent.com/api/dpdp/cms/loader.js" async></script>
